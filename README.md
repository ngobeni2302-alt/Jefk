# 🎵 Jeffrey Kay — Official Gospel Artist Website

The official responsive portfolio website for **Jeffrey Kay**, a Gospel singer, songwriter, and worship leader from **South Africa**. Built and developed by **valambyaT3ch**.

---

## 🎨 Color System (60 - 30 - 10 Rule)

- **60% White (`#FFFFFF` / `#F8FAFC`)**: Canvas background, card containers, and light section surfaces.
- **30% Dusty Blue (`#5C7C8D` / `#EBF1F5`)**: Navigation accents, section borders, category tags, system tabs bar, and highlights.
- **10% Black (`#0B0F17` / `#000000`)**: Core headlines, primary action buttons, active tab indicators, and vector icons.

---

## 🌟 Key Sections

1. **About Jeffrey Kay**:
   - Bio, origin (South Africa), genre (Gospel Music), active year, and official photo placeholder.
2. **Social Media Hub**:
   - Spotify, Instagram, YouTube, WhatsApp, X (Twitter), Apple Music, SoundCloud, and TikTok.
3. **Gospel Music & Discography**:
   - Gospel singles (*Grace & Salvation*), EP projects (*Heavenly Praise*), and live worship recordings.
4. **WhatsApp & Email Contact**:
   - Direct WhatsApp connection link + booking & inquiry email form.
5. **Developer Credits & Footer**:
   - Official branding for **valambyaT3ch** and contact email `valambyat3ch@gmail.com`.

## 🚀 How to Run the Website

### Step 1: Open Terminal in Project Directory
```bash
cd /home/wethinkcode/Desktop/Jefk
```

```bash

```

### Step 3: Start the Development Server
```bash

```

Open: 👉 **[http://localhost:5173](http://localhost:5173)**
