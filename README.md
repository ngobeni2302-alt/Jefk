# Jeffery Kay — Official Gospel Artist Website

The official responsive portfolio website for **Jeffery Kay**, a Gospel singer, songwriter, and worship leader from **Kwa-Thema, Springs, South Africa**. Developed and maintained by **ValambyaT3ch**.

---

## Live Demo

Visit the deployed website here: **[jefk.vercel.app](https://jefk.vercel.app/)**

---

## Color System (60 - 30 - 10 Rule)

- **60% White (`#FFFFFF` / `#F8FAFC`)**: Canvas background, card containers, and light section surfaces.
- **30% Dusty Blue (`#5C7C8D` / `#EBF1F5`)**: Navigation accents, section borders, category tags, system tabs bar, and highlights.
- **10% Black (`#0B0F17` / `#000000`)**: Core headlines, primary action buttons, active tab indicators, and vector brand icons.

1. **About Jeffery Kay**:
   - Biography covering his gospel calling, theatre background alongside Sipho Mnyakeni with Mzansi Khayalami, mission (*Reborn to Worship*), origin (*Kwa-Thema, Springs*), and official artist portrait.
2. **Gospel Music & Snippets**:

4. **Email Contact & Ministry Bookings**:
   - Direct gospel ministry inquiry form with strict required field validation, error feedback, and direct email client support.
5. **Developer Credits & Footer**:
   - Developed & Maintained by **ValambyaT3ch** with direct clickable email composer (`valambyat3ch@gmail.com`).

## How to Run the Website

### Step 1: Open Terminal in Project Directory
```bash
cd Jefk
```

### Step 2: Use a supported Node.js version
This project requires Node.js **18.0.0+**. Verify it with:

```bash
node --version
```

### Step 3: Install Dependencies (if not already done)
```bash
npm install
```

### Step 4: Start the Development Server
```bash
npm run dev
```

### Step 5: Open in Web Browser
Open: **[http://localhost:5173](http://localhost:5173)**
